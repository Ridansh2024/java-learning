## Key Concepts

### ArrayList vs HashMap vs HashSet
| Collection | Use When | Time Complexity (Search) |
|-----------|----------|-------------------------|
| ArrayList | Ordered list, access by index | O(n) |
| HashMap | Key-value lookup | O(1) |
| HashSet | Check existence, no duplicates | O(1) |
