# Weather Dashboard Frontend

React frontend for the weather dashboard project.

## Setup

1. Go to the frontend folder:
   ```bash
   cd projects/weather-dashboard/frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. (Optional) Configure backend URL:
   ```bash
   echo "REACT_APP_API_BASE_URL=http://localhost:8080/api/weather" > .env
   ```
4. Start app:
   ```bash
   npm start
   ```
